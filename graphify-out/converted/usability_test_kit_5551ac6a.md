ชุดทดสอบการใช้งาน (Usability Pilot Test) — WeEasyTrip
ใช้กับผู้ทดสอบ 3–5 คน คนละประมาณ 15 นาที ผลที่กรอกต้องเป็นของจริงเท่านั้น ใส่ในรายงานเป็น pilot test ระบุจำนวนคนตามจริง
1. ก่อนเริ่ม (ผู้จัดทำอ่านให้ผู้ทดสอบฟัง)
"กำลังทดสอบเว็บ ไม่ได้ทดสอบตัวคุณ ถ้าทำไม่ได้แปลว่าเว็บต้องปรับปรุง ผมจะไม่ช่วยจนกว่าคุณจะบอกว่าติด ช่วยพูดความคิดออกมาดัง ๆ ระหว่างใช้"

| ประสบการณ์วางแผนเที่ยวด้วยเว็บ/แอป | ☐ น้อย ☐ ปานกลาง ☐ มาก | อุปกรณ์ที่ใช้ | ☐ คอมพิวเตอร์ ☐ มือถือ |

2. ภารกิจและบันทึกผล (ผู้จัดทำกรอก จับเวลาแต่ละข้อ)
หยุดจับเวลาเมื่อทำเสร็จหรือผู้ทดสอบยอมแพ้ ถ้าติดเกิน 2–3 นาทีให้ถือว่าไม่สำเร็จ แล้วข้ามไปข้อถัดไป
| ข้อ | ภารกิจ | เกณฑ์ว่าสำเร็จ | สำเร็จ (Y/N) | เวลา (วินาที) | กดผิด / ลังเล (ครั้ง) | หมายเหตุ |
| --- | --- | --- | --- | --- | --- | --- |
| T1 | ค้นหาแผนเที่ยวเชียงใหม่ 3 วัน งบ 10,000 บาท 1 คน | เห็นแพ็กเกจ 3 ระดับ |  |  |  |  |
| T2 | ตั้งความชอบ: ชอบ "กิจกรรม" ไม่เอา "วัด" แล้วค้นหาใหม่ | แผนใหม่ไม่มีวัด |  |  |  |  |
| T3 | เปิดแพ็กเกจที่ชอบ แล้วสลับสถานที่ 1 แห่งในวันที่ 1 เป็นที่อื่น | แผนอัปเดต และอธิบายคำเตือน (ถ้ามี) ได้ |  |  |  |  |
| T4 | ลากการ์ดสลับลำดับสถานที่ 2 แห่งในวันเดียวกัน | ลำดับเปลี่ยนตามที่ลาก |  |  |  |  |

3. แบบสอบถาม SUS (ให้ผู้ทดสอบกรอกหลังทำภารกิจ)
ให้คะแนน 1 = ไม่เห็นด้วยอย่างยิ่ง · 2 = ไม่เห็นด้วย · 3 = เฉย ๆ · 4 = เห็นด้วย · 5 = เห็นด้วยอย่างยิ่ง
| ข้อ | ข้อความ | คะแนน (1–5) |
| --- | --- | --- |
| 1 | ฉันคิดว่าฉันอยากใช้ระบบนี้บ่อย ๆ |  |
| 2 | ฉันรู้สึกว่าระบบนี้ซับซ้อนโดยไม่จำเป็น |  |
| 3 | ฉันคิดว่าระบบนี้ใช้งานง่าย |  |
| 4 | ฉันคิดว่าฉันต้องมีผู้ช่วยทางเทคนิคจึงจะใช้ระบบนี้ได้ |  |
| 5 | ฉันพบว่าฟังก์ชันต่าง ๆ ของระบบนี้ทำงานรวมกันได้ดี |  |
| 6 | ฉันคิดว่าระบบนี้มีความไม่สอดคล้องกันมากเกินไป |  |
| 7 | ฉันคิดว่าคนส่วนใหญ่จะเรียนรู้การใช้ระบบนี้ได้อย่างรวดเร็ว |  |
| 8 | ฉันพบว่าระบบนี้ใช้งานยุ่งยากมาก |  |
| 9 | ฉันรู้สึกมั่นใจเมื่อใช้ระบบนี้ |  |
| 10 | ฉันต้องเรียนรู้หลายอย่างก่อนที่จะใช้ระบบนี้ได้ |  |

| คะแนน SUS ของผู้ทดสอบคนนี้ (0–100) |  |
