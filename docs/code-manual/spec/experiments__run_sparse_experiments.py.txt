@title การทดลองจังหวัดข้อมูลน้อย (sparse)
@role ทดสอบ Greedy GA และ Hybrid บนจังหวัดที่ข้อมูลน้อย 8 จังหวัด ด้วยกติกาและพารามิเตอร์เดียวกับการทดลองหลักของ [[experiments/run_province_experiments.py]] (เดิมมีชุดทริปข้ามจังหวัดข้างเคียงด้วย แต่ถอดฟังก์ชันนั้นออกจากระบบแล้ว) ผลคือ sparse_results*.json และ sparse_stats*.txt ที่ใช้ในตารางที่ 4.9 ของรายงาน

@@ 1-20 หัวไฟล์ ค่าคงที่
1-9: docstring อธิบายการทดลองและที่เก็บผล (sparse_results*.json และ sparse_stats*.txt)
10: นำเข้าโมดูลมาตรฐาน
11: ตัด `sys.argv` ให้โมดูลทดลองหลักอ่านจำนวนรอบจากอาร์กิวเมนต์แรกเท่านั้น
12-14: นำเข้า [[experiments/run_province_experiments.py]] (ในชื่อ `R`) [[algorithm/utils.py#load_data]] และ [[algorithm/utils.py#set_travel_profile]] และ `scipy.stats`
16: `TRIALS` จำนวนรอบ (ตั้งต้น 10)
17: `SPARSE` รายชื่อจังหวัดข้อมูลน้อย 8 จังหวัด
18: เลือกสถานการณ์จาก `SC_IDX`
19: ต่อท้ายชื่อไฟล์ผลลัพธ์ (ว่างสำหรับ S1 หรือ `_S2` `_S3`)
20: ตั้งจำนวนรอบให้โมดูลหลัก

@@ 23-27 โหลดข้อมูลจังหวัด
23-24: `load` โหลดสถานที่และโรงแรมของจังหวัดจากไฟล์ใน data/provinces
25-26: ตั้งโปรไฟล์เดินทางของจังหวัด (road factor และความเร็ว)
27: คืนจุดและโรงแรม

@@ 30-43 รันหนึ่งจังหวัด
30-34: ประกาศ `run` โหลดข้อมูล เลือกโรงแรมตามตำแหน่งของสถานการณ์ และคำนวณงบกิจกรรม
35: เตรียมผลลัพธ์พร้อมจำนวนจุด โรงแรม และร้านอาหาร
36-41: รันทั้งสามอัลกอริทึมด้วย `R.run_algo` (Greedy ครั้งเดียว) สรุปคะแนน เวลา จำนวนที่ผ่าน มื้อครบ และกิโลเมตรต่อวัน
42: ทดสอบ Mann-Whitney ทางเดียว (Hybrid มากกว่า GA)
43: คืนผล

@@ 46-57 จุดเริ่มต้นและบันทึกผล
46-51: วนทุกจังหวัดข้อมูลน้อย รันและพิมพ์สรุปบรรทัดเดียว
52: เขียน sparse_results*.json
53-56: เขียน sparse_stats*.txt แบบแยกคอลัมน์ด้วยแท็บ
57: พิมพ์ `saved`
