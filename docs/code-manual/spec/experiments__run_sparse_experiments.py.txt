@title การทดลองจังหวัดข้อมูลน้อย (sparse) และทริปข้ามจังหวัด
@role ทดสอบ Greedy GA และ Hybrid บนจังหวัดที่ข้อมูลน้อย 8 จังหวัดและทริปข้ามจังหวัด 4 คู่ ด้วยกติกาและพารามิเตอร์เดียวกับ [[experiments/run_province_experiments.py]] เลือกสถานการณ์ด้วยตัวแปรแวดล้อม `SC_IDX` (0=S1 1=S2 2=S3) ผลใช้เขียนส่วนจังหวัดข้อมูลน้อยในบทที่ 4 และ 5 ของรายงาน

@@ 1-20 หัวไฟล์ ค่าคงที่
1-8: docstring อธิบายการทดลองและที่เก็บผล (sparse_results*.json และ sparse_stats*.txt)
9: นำเข้าโมดูลมาตรฐาน
10: ตัด `sys.argv` ให้โมดูลทดลองหลักอ่านจำนวนรอบจากอาร์กิวเมนต์แรกเท่านั้น
11-13: นำเข้า [[experiments/run_province_experiments.py]] (ในชื่อ `R`) [[algorithm/utils.py#load_data]] และ [[algorithm/utils.py#set_travel_profile]] และ `scipy.stats`
15: `TRIALS` จำนวนรอบ (ตั้งต้น 10)
16: `SPARSE` รายชื่อจังหวัดข้อมูลน้อย 8 จังหวัด
17: `COMBOS` คู่จังหวัดข้างเคียงสำหรับทริปข้ามจังหวัด
18: เลือกสถานการณ์จาก `SC_IDX`
19: ต่อท้ายชื่อไฟล์ผลลัพธ์ (ว่างสำหรับ S1 หรือ `_S2` `_S3`)
20: ตั้งจำนวนรอบให้โมดูลหลัก

@@ 23-32 โหลดข้อมูลจังหวัดหรือคู่จังหวัด
23-27: `load` รับ slug เดี่ยวหรือ `a+b` โหลดข้อมูลของแต่ละจังหวัด
28-29: ถ้าเป็นหลายจังหวัด ใส่คำนำหน้า id ของแต่ละจังหวัดเพื่อไม่ให้ id ซ้ำ (เหมือน `_combo` ใน [[backend/main.py#get_province]])
30-31: ตั้งโปรไฟล์เดินทางจากจังหวัดแรกของคู่
32: คืนจุดและโรงแรม

@@ 35-48 รันหนึ่งพื้นที่
35-39: ประกาศ `run` โหลดข้อมูล เลือกโรงแรมตามตำแหน่งของสถานการณ์ และคำนวณงบกิจกรรม
40: เตรียมผลลัพธ์พร้อมจำนวนจุด โรงแรม และร้านอาหาร
41-46: รันทั้งสามอัลกอริทึมด้วย `R.run_algo` (Greedy ครั้งเดียว) สรุปคะแนน เวลา จำนวนที่ผ่าน มื้อครบ และระยะขับ
47: ทดสอบ Mann-Whitney ทางเดียว (Hybrid มากกว่า GA)
48: คืนผล

@@ 51-62 จุดเริ่มต้นและบันทึกผล

57: เขียน sparse_results*.json
58-61: เขียน sparse_stats*.txt แบบแยกคอลัมน์ด้วยแท็บ
