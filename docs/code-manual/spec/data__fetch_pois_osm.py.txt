@title ดึงสถานที่และโรงแรมของจังหวัดจาก OpenStreetMap (Overpass API)
@role หัวใจของท่อสร้างข้อมูลจังหวัด: ส่งคำค้นไปที่ Overpass API (ฟรี ไม่ต้องใช้คีย์) ตามขอบเขตของจังหวัดใน data/provinces.json แปลงข้อมูลดิบของ OSM เป็นสถานที่ (POI) และโรงแรมตามโครงสร้างเดียวกับ phuket.json เขียนเป็น data/provinces/<slug>.json ถูกเรียกจาก [[data/build_all_provinces.py]] ข้อจำกัดสำคัญคือคะแนนสถานที่ประเมินจากความสมบูรณ์ของข้อมูลใน OSM (ไม่ใช่รีวิวจริง) ราคาโรงแรมประมาณจากดาว และราคาร้านอาหารประมาณจากประเภทอาหาร ข้อมูลที่ได้ถูกโหลดโดย [[algorithm/utils.py#load_data]] และ [[backend/main.py]]
