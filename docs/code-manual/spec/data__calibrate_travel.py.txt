@@ 1-14 หัวไฟล์ ค่าคงที่
1-9: docstring: สุ่มคู่ POI/โรงแรม 40 คู่ (seed คงที่) เรียก OSRM คำนวณ road_factor = Σ ระยะถนน ÷ Σ ระยะเส้นตรง และ speed_kmh = Σ ระยะถนน ÷ Σ เวลาขับ (แบบรถไม่ติด) วิธีรัน `python calibrate_travel.py [slug ...]`
10: นำเข้าโมดูลมาตรฐานสำหรับ JSON คณิตศาสตร์ ไฟล์ สุ่ม และเรียก HTTP
12: `HERE` โฟลเดอร์ของสคริปต์ (คือ data/)
13: `OSRM` แม่แบบ URL ของบริการเส้นทางสาธารณะ (ขับรถ ไม่ขอรูปเส้นทาง)
14: `PAIRS = 40` จำนวนคู่ที่สุ่มต่อจังหวัด

@@ 17-22 ระยะเส้นตรง

@@ 25-38 เรียก OSRM
