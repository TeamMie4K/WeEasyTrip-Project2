@title NSGA-II หลายวัตถุประสงค์ (Pareto front)
@role สร้างชุดแผนทางเลือกที่ "ไม่มีแผนใดดีกว่าทุกด้าน" ตามวัตถุประสงค์ 3 ข้อ คือคะแนนรวม (มากสุด) ความหลากหลายของหมวดต่อวัน (มากสุด) และระยะขับรวม (น้อยสุด) ให้ผู้ใช้เลือก trade-off เอง ยืมตัวดำเนินการ GA และตัวซ่อมแผนจาก [[algorithm/hybrid.py]] เริ่มประชากรด้วย [[algorithm/greedy.py#greedy_solve]] และตรวจแผนด้วย [[algorithm/utils.py#evaluate_route]] ถูกเรียกจาก [[backend/main.py]] และ [[experiments/run_pareto_experiments.py]]

@@ 43-55 ความ "ชนะ" แบบ constraint-domination

@@ 58-83 จัดอันดับแบบไม่ถูกครอบงำ
