@title การทดลอง RL: คุณภาพ seed และ Hybrid ที่ใช้ RL seed
@role ประเมินตัวแทน RL ของ [[algorithm/rl.py]] (ค่า θ จาก [[experiments/train_rl.py]]) สองส่วน คือ (1) คุณภาพของแผนเริ่มต้น Greedy เทียบ RL แบบ deterministic (2) Hybrid ปกติเทียบ Hybrid ที่ใช้ RL เป็น seed (Wilcoxon แบบจับคู่) ครอบคลุมสถานการณ์ที่เคยฝึก (S1–S3) และที่ไม่เคยฝึก (H1 H2) ผลคือตาราง 4.7 ในรายงาน
