@title สลับภาษาไทย/อังกฤษด้วยพจนานุกรมและ regex
@role แปลข้อความบนหน้าเว็บโดยไม่ต้องเขียนข้อความสองภาษาไว้ในโค้ดแต่ละที่: เก็บข้อความไทยเป็นต้นฉบับ แล้วแปลทับ DOM ด้วยพจนานุกรม (D) รูปแบบ regex (P) และตารางชื่อจังหวัด สถานที่ โรงแรมที่อ่านจากตัวแปร STATE ใน [[frontend/app.js]] จากนั้นใช้ MutationObserver เฝ้าดูข้อความใหม่ที่แอปสร้างตอนทำงาน ปุ่ม EN/TH ถูกแทรกเข้าแถบบนของ [[frontend/index.html]] ภาษาที่เลือกเก็บใน localStorage และเปิดเป็นตัวแปร WET_LANG ให้ [[frontend/tutorial.js]] [[frontend/extras.js]] และ [[frontend/app.js]] อ่านได้ ทั้งนี้ข้อความที่ไม่อยู่ในพจนานุกรมจะแสดงเป็นภาษาไทยตามเดิม

@@ 73-92 รูปแบบ regex

@@ 93-93 ตารางชื่อจังหวัด
