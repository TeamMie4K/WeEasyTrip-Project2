@title ทดสอบสาเหตุที่ Hybrid แพ้ในพิจิตร
@role ทดสอบสมมติฐานว่าทำไม Hybrid ได้คะแนนต่ำกว่า GA และ Greedy ในจังหวัดที่ร้านอาหารไม่พอ (พิจิตร) สมมติฐานคือขั้นซ่อมแผนใน [[algorithm/hybrid.py#hybrid_solve]] ถอดสถานที่ท่องเที่ยวคะแนนต่ำสุดเมื่อวันนั้นมีมื้อไม่ครบ แม้สาเหตุคือไม่มีร้านให้เติม จึงเสียสถานที่โดยไม่ได้มื้อเพิ่ม สคริปต์เทียบ Hybrid ปัจจุบันกับ Hybrid ที่แก้ให้ถอดเฉพาะเมื่อร้านอาหารพอสำหรับทั้งทริป ผลคือ results/phichit_cause.json (เป็นที่มาของการแก้ใน hybrid.py ที่ใช้อยู่ตอนนี้ และตารางที่ 4.10)
