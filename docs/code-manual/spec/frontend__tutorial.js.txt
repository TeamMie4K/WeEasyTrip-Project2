@title วิธีใช้แบบนำชม (Tutorial) สำหรับผู้ใช้ครั้งแรก
@role แสดงกล่องนำชมทีละขั้นพร้อมไฮไลต์องค์ประกอบ ครั้งแรกที่เข้าเว็บหรือเมื่อห่างหายเกิน 30 วัน มีสองชุด: ชุดฟอร์มค้นหา (FORM) และชุดหน้ารายละเอียดแผน (DETAIL) ซึ่งแสดงหลังเปิดแผนครั้งแรก โดยห่อฟังก์ชัน `renderDetail` ของ [[frontend/app.js#renderDetail]] ปุ่ม "?" ถูกแทรกข้างปุ่มธีมที่อยู่ใน [[frontend/index.html]] ภาษาอ่านจากตัวแปร WET_LANG ที่ [[frontend/i18n.js]] กำหนด และสไตล์ของกล่อง (คลาส tut) อยู่ใน [[frontend/style.css]]

@@ 1-11 หัวไฟล์ และสถานะการเข้าใช้
1-2: คอมเมนต์อธิบายเงื่อนไขการแสดง และการใช้ localStorage แบบไม่ทำให้หน้าพังเมื่อใช้ไม่ได้
3: เปิด IIFE
4: ค่าคงที่ `DAY` และ `RETURN_AFTER` (30 วัน)
5: `get` อ่านตัวเลขจาก localStorage ถ้าผิดพลาดคืน 0
6: `set` เขียนค่าลง localStorage ถ้าผิดพลาดก็ข้าม
7: `en` ตรวจว่าภาษาปัจจุบันเป็นอังกฤษ
8: อ่านเวลาปัจจุบัน เวลาเข้าใช้ครั้งก่อน และเวลาที่ดู tutorial จบ
9: บันทึกเวลาเข้าใช้ครั้งนี้
10: `due` = ยังไม่เคยดูจบ หรือห่างหายเกิน 30 วัน
11: ตัวแปรสถานะ: `detailDue` ว่าจะแสดงชุดรายละเอียดหรือไม่ `el` กล่องนำชม `idx` ขั้นปัจจุบัน `steps` รายการขั้น `onEnd` ฟังก์ชันเมื่อจบ

@@ 13-27 ข้อความของแต่ละขั้น
13-20: `FORM` ชุดนำชมฟอร์ม: แต่ละขั้นมีตัวเลือก `sel` (CSS selector ขององค์ประกอบที่ไฮไลต์ ขั้นต้อนรับไม่มี) และข้อความไทยกับอังกฤษ [หัวเรื่อง, เนื้อความ]
21-27: `DETAIL` ชุดนำชมหน้ารายละเอียด: ลากการ์ด เปลี่ยนหรือลบสถานที่ ดูเส้นทางบนแผนที่ คลิกหมุด และปุ่มบันทึก/แชร์/ส่งออก

@@ 29-30 รีเซ็ตและปิด
29: `resetLanding` เลื่อนหน้า landing กลับขึ้นบนสุด
30: `close` ปิดกล่อง ถอดตัวฟังเหตุการณ์ และถ้าจบจริงเรียก `onEnd`

@@ 31-39 สร้างกล่องนำชม
31-34: `build` สร้างโครงสร้าง HTML (ไฮไลต์ การ์ด หัวเรื่อง เนื้อความ จุดบอกขั้น ปุ่มข้าม/ก่อนหน้า/ถัดไป) แล้วต่อเข้า body
35-37: ผูกปุ่ม: ข้ามคือปิด ก่อนหน้าไปขั้นก่อน ถัดไปไปขั้นถัดไปหรือจบเมื่อถึงขั้นสุดท้าย
38: ฟังการปรับขนาดและเลื่อนหน้าเพื่อจัดตำแหน่งใหม่

@@ 40-50 ไปยังขั้นที่กำหนด
40-41: `go` หนีบเลขขั้นให้อยู่ในช่วง เลือกข้อความตามภาษา
42-43: ถ้าองค์ประกอบเป้าหมายมองเห็นแต่ใกล้ขอบจอ เลื่อนหน้าให้เข้ามา (ไม่ใช้ scrollIntoView เพราะ .landing-screen ซ่อนส่วนที่ล้น จะเลื่อนภายในแล้วกลับไม่ได้)
44: ใส่หัวเรื่องและเนื้อความ
45: วาดจุดบอกขั้น ขั้นปัจจุบันเป็นสีเข้ม
46-48: ตั้งข้อความปุ่มตามภาษา ซ่อนปุ่มก่อนหน้าในขั้นแรก ขั้นสุดท้ายเปลี่ยนปุ่มถัดไปเป็น "เริ่มใช้งาน"
49: จัดตำแหน่งและเติมคลาส ready ให้แสดง

@@ 51-63 จัดตำแหน่งไฮไลต์และการ์ด
51-52: `placeSoon` รวมการจัดตำแหน่งหลายครั้งให้เหลือหนึ่งครั้งต่อเฟรมด้วย requestAnimationFrame
53-54: `place` ออกถ้าไม่มีกล่อง แล้วอ่านขั้นปัจจุบัน เป้าหมาย ไฮไลต์ และการ์ด
55: ถ้าไม่มีเป้าหมายหรือมองไม่เห็น ซ่อนไฮไลต์ วางการ์ดกลางจอ และทำพื้นหลังมืด
56-57: มีเป้าหมาย: เอาพื้นหลังมืดและการ์ดกลางจอออก
58-59: คำนวณกรอบเป้าหมายและวางไฮไลต์ขยายออกรอบละ 8 พิกเซล
60: ความกว้างการ์ดไม่เกิน 340 และเช็กว่าใต้เป้าหมายมีที่พอ
61-62: วางการ์ดไว้ใต้เป้าหมายถ้าพอ ไม่พอวางไว้เหนือ และจัดกลางโดยไม่ล้นจอ

@@ 64-65 เริ่มชุดนำชม
64: `start` รีเซ็ต ปิดของเดิม ตั้งชุดขั้นและฟังก์ชันจบ แล้วสร้างและไปขั้นแรก
65: `window.startTutorial` เปิดชุดฟอร์มและบันทึกเวลาว่าดูจบเมื่อจบ (ให้ปุ่มอื่นเรียกได้)

@@ 67-71 เมื่อหน้าเว็บโหลดเสร็จ
67: รอ DOMContentLoaded
68: แทรกปุ่ม "?" ก่อนปุ่มธีม
69: คลิกปุ่มแล้วเปิดชุดฟอร์มใหม่ และอนุญาตให้ชุดรายละเอียดแสดงด้วย
70: ถ้าถึงเวลาแสดง เปิดอัตโนมัติหลัง 1.2 วินาที

@@ 72-82 ผูกกับการเปิดแผน
72: คอมเมนต์อธิบาย
73-75: `wrap` รอจนฟังก์ชัน [[frontend/app.js#renderDetail]] ถูกประกาศ (ลองซ้ำทุก 300 มิลลิวินาที) แล้วเก็บฟังก์ชันเดิม
76-79: แทนที่ `renderDetail` ด้วยตัวห่อ: เรียกของเดิมก่อน แล้วถ้าถึงเวลาและไม่มีกล่องค้าง แสดงชุดรายละเอียดหลัง 0.9 วินาที (แสดงครั้งเดียวต่อรอบ)
81-82: เรียก `wrap` และปิด IIFE
