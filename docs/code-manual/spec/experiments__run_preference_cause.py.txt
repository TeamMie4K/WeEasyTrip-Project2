@role หาสาเหตุที่การตั้งความชอบ (ชอบกิจกรรม/จุดชมวิว) ไม่เพิ่มสัดส่วนสถานที่หมวดนั้นอย่างมีนัยสำคัญใน 8 จังหวัดที่มีสถานที่หมวดนั้นเพียง 6-10 จุด ตรวจสองสมมติฐาน คือน้ำหนักถ่วง `LIKE_BOOST` (ค่าปัจจุบัน 1.0) น้อยเกินไปเมื่อเทียบกับช่วงคะแนนสถานที่ หรือสถานที่ในหมวดที่ชอบมีคะแนนต่ำหรืออยู่ไกลโรงแรม วิธีคือรัน [[algorithm/hybrid.py#hybrid_solve]] ด้วย `LIKE_BOOST` 1.0 เทียบ 3.0 และ 5.0 ผ่านฟังก์ชันของ [[backend/main.py]] ผลคือ results/preference_cause.json ที่ใช้อธิบายผลความชอบในรายงาน
