@title วินิจฉัยผลที่ผิดคาด
@role หาสาเหตุของสองผลที่ไม่เป็นไปตามคาดในการทดลองหลัก ส่วนที่ 1 ทำไม Hybrid ไม่ชนะ GA ในจังหวัดข้อมูลน้อย 4 จังหวัด (พิจิตร ชัยภูมิ กาฬสินธุ์ สิงห์บุรี) โดยวัดคะแนนดิบ ระยะขับ จำนวนสถานที่และมื้อต่อวัน และค่าเป้าหมายที่หักระยะและเวลา เทียบกับเพดานคะแนน ส่วนที่ 2 ทำไมความชอบหมวดกิจกรรม/จุดชมวิวไม่เพิ่มสัดส่วนในบางจังหวัด โดยนับจำนวนสถานที่ในหมวดที่ชอบของแต่ละจังหวัด ผลคือ results/diagnose.json ที่ใช้ในตารางที่ 4.9-4.10 และหัวข้อวินิจฉัยของรายงาน ใช้ผลของ [[experiments/run_preference_experiments.py]] เป็นข้อมูลนำเข้า
