@title ตรวจค่าเป้าหมายของ Hybrid ในพิจิตร
@role หาว่าทำไมใน S2 ของพิจิตร Hybrid ได้ค่าเป้าหมาย (คะแนน − 0.3 × กม. − 0.01 × นาที) ต่ำกว่า GA แม้แก้ขั้นซ่อมแผนแล้ว เทียบ Greedy GA Hybrid และ Hybrid ที่ปิด ILS ด้วยกติกาและพารามิเตอร์ของ [[experiments/run_province_experiments.py]] 10 รอบ แล้วแยกค่าเป้าหมายเป็นส่วนของคะแนน ระยะทาง และเวลา ผลคือ results/phichit_objective.json ที่ใช้ในหัวข้อ 4.2.9 ของรายงาน ต่อด้วย [[experiments/run_seed_penalty_check.py]] ที่ทดสอบสาเหตุที่พบ

@@ 1-22 หัวไฟล์ ค่าคงที่ และโหลดข้อมูล
1-8: docstring อธิบายคำถาม วิธีเทียบ และที่เก็บผล
9-13: นำเข้าโมดูลมาตรฐาน [[experiments/run_province_experiments.py]] (ชื่อ `E`) [[algorithm/hybrid.py]] และ [[algorithm/utils.py#evaluate_route]]
15-17: ใช้สถานการณ์ S2 จำนวน 10 รอบ และตัวเก็บ seed ของรอบปัจจุบัน
20-22: `load` โหลดข้อมูลจังหวัด เลือกโรงแรม และคำนวณงบกิจกรรมด้วย `E.setup`

@@ 25-34 วัดแผนหนึ่งแผน
25-34: `measure` ประเมินแผนด้วย `evaluate_route` แล้วคืนคะแนนดิบ กม./วัน ชม./วัน จำนวนสถานที่และมื้อต่อวัน จำนวนวันที่มื้อไม่ครบ และค่าเป้าหมายแยกเป็นส่วนของคะแนน ระยะ และเวลา

@@ 37-45 รันหลายรอบ
37-45: `run` รันอัลกอริทึมหนึ่งตัวด้วย seed 0-9 แล้วเฉลี่ยทุกตัวชี้วัด พร้อมนับจำนวนแผนที่ผ่านข้อจำกัด

@@ 48-54 รายการอัลกอริทึมที่เทียบ
48-54: `make_fns` กำหนด Greedy GA และ Hybrid ผ่าน `E.run_algo` และ Hybrid ที่ปิด ILS (`ils=False`) เพื่อดูว่า ILS ช่วยลดช่องว่างได้เท่าใด

@@ 57-65 จุดเริ่มต้น
