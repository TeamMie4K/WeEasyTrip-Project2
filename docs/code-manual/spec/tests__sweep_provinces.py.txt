@title กวาดทดสอบ API ทุกจังหวัด
@role ยิงคำขอ `/api/packages` ของ [[backend/main.py]] ผ่าน FastAPI TestClient กับทุกชุดข้อมูลจังหวัด (78 ชุด) 9 เงื่อนไข (งบ จำนวนวัน จำนวนคน รวมโรงแรมหรือไม่) และ 3 ระดับแพ็กเกจ รวม 2,106 แผน แล้วตรวจว่าทุกแผนผ่านข้อจำกัด ไม่เกินงบ ทุกวันมีสถานที่ท่องเที่ยว ครบ 4 แห่งต่อวัน และมีมื้ออาหาร 2 มื้อต่อวัน ผลคือ experiments/results/sweep_provinces.json ที่ใช้ในตารางที่ 4.12 ของรายงาน

@@ 1-16 หัวไฟล์ เงื่อนไขทดสอบ
1-7: docstring อธิบายสิ่งที่ตรวจ และวิธีรัน (`python tests/sweep_provinces.py [จำนวน process]`)
8-12: นำเข้าโมดูล ปิดตัวจำกัดอัตราคำขอเฉพาะตอนทดสอบ (`WET_RATE_PER_MIN`) และเพิ่มโฟลเดอร์ algorithm กับ backend เข้า path
14-16: `CASES` เงื่อนไข 9 แบบ (งบรวม จำนวนวัน จำนวนคน รวมโรงแรมในงบ)

@@ 19-39 ทดสอบกลุ่มจังหวัดหนึ่งชุด
19-24: `work` สร้าง TestClient ตั้งไฟล์เซสชันชั่วคราวแยกต่อ process (ไม่เขียนทับไฟล์จริง)
25-31: ต่อจังหวัด จำกัดจำนวนวันตาม `max_days` ของจังหวัดเหมือนหน้าเว็บ แล้วส่งคำขอ ถ้าไม่ใช่ 200 บันทึกข้อผิดพลาด
32-38: ต่อแพ็กเกจ นับสถานที่ท่องเที่ยวและมื้อต่อวัน แล้วบันทึกธง valid เกินงบ วันว่าง วันที่ที่เที่ยวน้อยกว่า 4 วันที่มื้อไม่ครบ จำนวนหมายเหตุ และข้อความผิดข้อจำกัด
39: คืนผลของกลุ่ม

@@ 42-57 จุดเริ่มต้น และสรุปผล
42-49: แบ่งจังหวัดเป็นกลุ่มตามจำนวน process แล้วรันพร้อมกันด้วย `multiprocessing.Pool`
50-55: สรุปจำนวนแผน ข้อผิดพลาด HTTP แผนผิดข้อจำกัด เกินงบ ไม่มีสถานที่ มีวันว่าง วันที่สถานที่น้อย มื้อขาด มีหมายเหตุ และคำขอที่ถูกจำกัดจำนวนวัน
56-57: เขียน sweep_provinces.json และพิมพ์สรุป
