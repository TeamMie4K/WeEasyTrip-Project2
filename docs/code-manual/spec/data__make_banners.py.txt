@title สร้างภาพแบนเนอร์ SVG ประจำจังหวัด
@role สคริปต์สร้างภาพวาดเชิงนามธรรมขนาด 1600×640 ของทุกจังหวัดเป็น SVG ไว้ที่ frontend/img/provinces/<slug>.svg ตามลักษณะพื้นที่ (เมือง วัด ชายฝั่ง ภูเขา หรือทุ่งนา) และสีตามภาค หน้าเว็บ ([[frontend/app.js]]) ใช้ภาพนี้เป็นหัวการ์ดจังหวัด ถ้าวางไฟล์ <slug>.jpg ไว้ในโฟลเดอร์เดียวกัน หน้าเว็บจะใช้ภาพถ่ายแทน ใช้รายชื่อภาคจาก [[data/thai_provinces.py]]

@@ 1-23 หัวไฟล์ ค่าคงที่ และจานสี
1-5: docstring อธิบายหน้าที่ ที่เก็บผล และวิธีรัน
7: นำเข้า `json` `os` `random`
9-11: `ROOT` ราก repo `OUT` โฟลเดอร์ปลายทาง และขนาดภาพ `W, H`
12-13: `COAST` ชุดจังหวัดชายฝั่ง
14: `CITY` ชุดจังหวัดเมือง (กรุงเทพฯ และปริมณฑล)
15: `TEMPLE` ชุดจังหวัดมรดกทางวัฒนธรรม (วัดและเจดีย์)
16-23: `PAL` จานสีของแต่ละภาค: สีบนฟ้า สีล่างฟ้า สีเงาไกล สีเงาใกล้

@@ 26-34 วาดเส้นสันเขา

@@ 37-41 วาดเจดีย์
37-41: `chedi` สร้างพาธรูปเจดีย์ที่ตำแหน่ง x ฐาน base ความสูง h และสี fill

@@ 44-96 สร้างภาพของหนึ่งจังหวัด
44-48: ประกาศ `make` ตั้งตัวสุ่มจาก slug (ภาพของแต่ละจังหวัดคงเดิมทุกครั้ง) เลือกจานสีตามภาค สุ่มการหมุนสีและตำแหน่งดวงอาทิตย์
49-53: เริ่ม SVG: ไล่สีท้องฟ้า แสงเรืองรอง ดวงอาทิตย์
54-56: วาดเมฆ 5 ก้อน
57: ตรวจว่าเป็นจังหวัดชายฝั่ง
58-62: ภูเขาซ้อนกัน 3 ชั้นสำหรับภาคเหนือและจังหวัดภูเขาที่ระบุ พร้อมแถบหมอก
63-71: ฉากเมือง: สุ่มตึกสูงต่ำและหน้าต่างสีเหลือง
72-76: ฉากวัด: เจดีย์ 3–5 องค์
77-85: ฉากทะเล: เกาะไกล พื้นน้ำ คลื่น ฝั่ง และเรือใบ
86-94: ฉากทุ่งนา: เนินไกล คันนา ฝั่งใกล้ และต้นตาล 2–4 ต้น
95-96: ซ้อนชั้นมืดบาง ๆ ปิดแท็ก SVG และคืนข้อความ
