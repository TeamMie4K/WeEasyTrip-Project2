@title วิเคราะห์ความไวของพารามิเตอร์
@role ตรวจว่าข้อสรุป "Hybrid ดีกว่า GA และ Greedy" ยังคงอยู่เมื่อเปลี่ยนพารามิเตอร์ที่ผู้พัฒนาเลือกเอง 4 ตัว คือ `DIST_WEIGHT` (หักคะแนนต่อกิโลเมตร) `GREEDY_KM_PENALTY` (ค่าปรับกิโลเมตรของ Greedy) `TRAFFIC_FACTOR` (ตัวคูณเวลาเดินทาง) และ `TIME_WEIGHT` (หักคะแนนต่อนาที) ปรับทีละตัว ตัวอื่นคงค่าเดิม รันสถานการณ์ S2 บน 4 จังหวัดหลักด้วยกติกาของ [[experiments/run_province_experiments.py]] ผลคือ results/sensitivity_*.json ที่ใช้ในตารางที่ 4.11 ของรายงาน
