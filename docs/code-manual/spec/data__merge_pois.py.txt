@title รวมข้อมูล OSM ใหม่กับข้อมูลเดิมของภูเก็ต (legacy)
@role สคริปต์รุ่น Project 1 ใช้เฉพาะภูเก็ต: รวมสถานที่ที่ดึงจาก OSM ใหม่กับร้านอาหาร กิจกรรม และคาเฟ่จากข้อมูลเดิม (เพราะรอบนั้น OSM ดึงร้านอาหารไม่ได้เนื่องจาก rate limit) ผลเป็น phuket_pois_merged.json ที่ต้องตรวจก่อนคัดลอกไปเป็น provinces/phuket.json จังหวัดอื่นไม่ต้องใช้ไฟล์นี้เพราะ [[data/fetch_pois_osm.py]] สร้างไฟล์จังหวัดตรง ๆ

@@ 1-23 หัวไฟล์ และฟังก์ชันอ่าน/เขียนไฟล์
1-6: docstring ระบุว่าเป็นของเก่า (legacy) สำหรับภูเก็ต และวิธีรัน
8-9: นำเข้า `json` และ `Counter`
15-18: `load` โหลดไฟล์ JSON คืน dict
20-23: `save` เขียน dict เป็น JSON (รองรับภาษาไทย มีย่อหน้า 2 ช่อง)

@@ 29-47 โหลดและแยกข้อมูล
29-31: โหลดข้อมูลเดิม (provinces/phuket.json) และข้อมูล OSM ใหม่
33-35: แยกสถานที่เดิม โรงแรมเดิม และสถานที่จาก OSM
37-40: เก็บร้านอาหาร กิจกรรม และคาเฟ่จากข้อมูลเดิม
43: เลือกสถานที่จาก OSM ที่ไม่ใช่ร้านอาหาร
46-47: เตรียมรายการผลรวมและชุดชื่อที่เห็นแล้ว (กันซ้ำ)

@@ 53-76 รวมข้อมูลและกำหนด id ใหม่
53-60: `add_pois` เพิ่มจุดเข้าผลรวมโดยกรองซ้ำด้วยชื่ออังกฤษตัวพิมพ์เล็ก (ข้ามชื่อว่าง)
62-63: ลำดับความสำคัญแรก: จุดจาก OSM ที่ไม่ใช่ร้านอาหาร (ใหม่และครบกว่า)
65-72: เติมกิจกรรม คาเฟ่ และร้านอาหารจากข้อมูลเดิมตามลำดับ
74-76: กำหนด id ใหม่ให้เรียงลำดับ รูปแบบ `P01`, `P02`, ...

@@ 82-93 สรุปและบันทึก
82-87: นับจำนวนสถานที่ตามหมวดและพิมพ์พร้อมจำนวนโรงแรม
90-92: เขียน phuket_pois_merged.json
93: เตือนให้ตรวจแล้วคัดลอกเป็น provinces/phuket.json
