## เฟส 1 — ขยายจังหวัด (เริ่มตรงนี้)
เป้าหมาย: เลือกจังหวัดแล้วได้แพ็กเกจจากข้อมูลของจังหวัดนั้น เริ่ม 3 จังหวัด: เชียงใหม่, กระบี่, เกาะสมุย (สุราษฎร์ธานี)

1.1 แยกข้อมูลเป็นรายจังหวัด
- ย้ายเป็น `data/provinces/<slug>.json` (schema เดิม) + `data/provinces.json` เก็บ slug, ชื่อไทย/อังกฤษ, bbox, center lat/lng, zoom
- ย้าย `phuket_pois.json` เข้าโครงใหม่ ห้ามเปลี่ยน schema ของ POI

1.2 Data pipeline รับ province เป็นพารามิเตอร์
- `fetch_pois_osm.py <slug>` อ่าน bbox จาก `provinces.json`; `merge_pois.py <slug>`
- เกณฑ์คุณภาพต่อจังหวัด: POI ≥ ~100 จุด ครบ 7 หมวด, ร้านอาหารพอสำหรับ lunch+dinner ทุกวัน, โรงแรม ≥ 15 แห่งครอบคลุม 3 ระดับราคา
- ตรวจ: พิกัดอยู่ใน bbox, ไม่มี id ซ้ำ, score/cost/เวลาเปิด-ปิดไม่ว่าง; `cost`/`open_min` ที่ OSM ไม่มีใช้ค่า default ตามหมวด (ตารางเดียวใน pipeline)

1.3 Backend
- โหลดทุกจังหวัดตอน start เป็น dict `{slug: (POIS, HOTELS)}`
- `GET /api/provinces`; `GET /api/pois?province=`; `PackageRequest` และ `RecomputeRequest` เพิ่ม `province` (default `phuket` เพื่อไม่ทำให้ client เดิมพัง); slug ไม่รู้จัก → 404
- ตัด global `POI_BY_ID`/`HOTEL_BY_ID` ให้ผูกกับจังหวัด

1.4 Frontend
- สร้างรายการใน dropdown จาก `/api/provinces`; ส่ง `province` ในทุก request
- แผนที่ recenter ตาม center/zoom ของจังหวัด; ข้อความที่ hardcode "ภูเก็ต" ใน `index.html`/`app.js` ใช้ชื่อจังหวัดแทน; แสดงจำนวน POI/โรงแรมของจังหวัดที่เลือก

1.5 ตรวจสอบ
- รัน 3 algorithm บนแต่ละจังหวัด งบต่ำ/กลาง/สูง ทุกแพ็กเกจต้อง `valid` และมี pattern attr-attr-lunch-attr-attr-dinner
- เฟสนี้ยังไม่แตะ algorithm

เสร็จเมื่อ: 4 จังหวัดใช้งานได้ครบ flow (ค้นหา → แพ็กเกจ → รายละเอียด → swap) และ experiment script รันได้ทุกจังหวัด

## เฟส 2 — ปรับ Hybrid และ re-optimization
- Re-optimization: `/api/recompute` รัน Hybrid ใหม่เมื่อผู้ใช้ swap/ลบ POI โดยล็อกจุดที่ผู้ใช้เลือกไว้
- เวลาเดินทาง: เปลี่ยนจาก haversine × ค่าคงที่เป็นตัวคูณตามจังหวัด/โหมด (ข้อจำกัดที่รายงานระบุ); OSRM เป็นทางเลือกถ้ามีเวลา
- Multi-objective แบบง่าย: เพิ่ม diversity ของหมวดหมู่ใน fitness (ไม่ทำ Pareto เต็มรูปแบบ)
- ทดลองซ้ำด้วย `experiments/run_experiments.py` เทียบ Hybrid เดิม vs ใหม่ ทุกจังหวัด (Kruskal-Wallis ตามแบบเดิม)

- เพิ่มฟิลด์ใน request + UI; ต้องเช็กว่า filter แล้วยังมี POI พอสร้างแพ็กเกจ ไม่พอ → แจ้งผู้ใช้
